[02] CLI Fundamental

Perintah Dasar Jaringan

1. Cek Antarmuka & IP Address iproute2
$ ip a

Melihat daftar antarmuka aktif dan alokasi alamat IPv4/IPv6.

2. Remote Access Server via SSH openssh
$ ssh user@192.168.1.50

Membuka sesi terminal jarak jauh terenkripsi ke router atau server.

3. Uji Konektivitas Host (ICMP Echo) iputils
$ ping -c 4 8.8.8.8

Memeriksa responsivitas dan latensi koneksi ke server tujuan.

4. Cek Port & Layanan Terbuka ss utility
$ ss -tuln

Memeriksa port TCP/UDP lokal yang sedang dalam status listening.

[03] Pre-installed Network Tools

Toolkit Jaringan Netra OS (14 Alat Utama)

Ubuntu 24.04 LTS Optimized & Ready to Use

[01] Packet Sniffer GUI

Wireshark

Menganalisis paket data dan inspeksi protokol mendalam via GUI.

$ wireshark &
[02] Port Scanner CLI

Nmap

Memetakan topologi jaringan, memindai port terbuka, dan mendeteksi layanan perangkat.

$ nmap -sV -O 192.168.1.0/24
[03] Route Diagnostic CLI

Traceroute

Menelusuri jalur rute perjalanan paket data menuju tujuan.

$ traceroute google.com
[04] Path Monitoring Interactive

MTR-tiny

Memantau rute jaringan sekaligus melacak kehilangan paket (packet loss) secara real-time.

$ mtr 1.1.1.1
[05] DNS Diagnostic dig/nslookup

Dnsutils

Menyediakan utilitas pemeriksaan DNS seperti dig dan nslookup.

$ dig +short domain.id
[06] Classic Suite ifconfig/netstat

Net-tools

Menyediakan utilitas manajemen jaringan klasik seperti ifconfig dan netstat.

$ ifconfig -a
[07] Bandwidth Test Benchmark

Iperf3

Menguji dan mengukur performa bandwidth serta kapasitas throughput jaringan.

$ iperf3 -c 10.0.0.1 -t 30
[08] Remote Desktop GUI Client

Remmina

Klien remote access GUI untuk mengelola server dan router via SSH, RDP, dan VNC.

$ remmina &
[09] Serial & SSH GUI/Terminal

PuTTY

Klien terminal remote access untuk koneksi SSH, Telnet, dan Serial.

$ putty &
[10] Subnetting Calculator

Ipcalc

Kalkulator subnetting untuk menghitung alokasi IP address, netmask, dan CIDR.

$ ipcalc 192.168.1.0/24
[11] CLI Capture libpcap

Tcpdump

Alat analisis dan penangkapan paket data berbasis terminal (CLI) yang ringan.

$ tcpdump -nn -i any
[12] Tunneling VPN Client/Server

OpenVPN

Utilitas pengujian dan manajemen koneksi virtual private network (VPN).

$ openvpn --config client.ovpn
[13] Web & Router UI Browser

Brave Browser

Browser default untuk mengakses panel manajemen router dan dokumentasi jaringan.

$ brave-browser &

openssh-server

[05] Alur Troubleshooting

Diagnosis Masalah Koneksi

  1. L1/L2
    Link Fisik & IP Interface

    Jalankan ip link untuk memastikan kabel terpasang atau status interface UP dan memiliki IP address valid.

  2. L3
    Gateway Reachability

    Ping gateway terdekat (ip route show default) untuk memastikan router merespons paket ICMP.

  3. L7
    DNS Lookup & HTTP Handshake

    Gunakan curl -Ivv https://domain untuk menguji validasi sertifikat SSL/TLS dan resolusi nama.

[06] Etika & Keamanan

Catatan Keamanan & Tanggung Jawab

Seluruh software yang disertakan dalam Netra OS ditujukan secara eksklusif untuk kepentingan edukasi, audit sistem resmi, diagnosa mandiri, dan pemeliharaan jaringan legal.
