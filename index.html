Welcome to
Netra OS

Distro Linux berbasis Ubuntu 26.04 LTS dengan desktop GNOME, yang dirancang khusus untuk pembelajaran, analisis lalu lintas data, dan administrasi jaringan komputer. Menyatukan berbagai toolkit jaringan dalam satu sistem agar praktis digunakan untuk pengujian dan troubleshooting.

Selamat datang di Netra OS! Mulailah dari pemeriksaan koneksi sederhana, pelajari jalur dan layanan jaringan, lalu lanjutkan ke analisis paket serta pengujian performa. Gunakan seluruh alat secara bertanggung jawab dan hanya pada jaringan atau perangkat yang diizinkan.

Bagian 01 Quick Start

Memulai Netra OS

Ikuti 5 langkah awal untuk mengenal lingkungan desktop GNOME, membuka terminal, dan memverifikasi konektivitas jaringan dasar.

1

Masuk ke Desktop GNOME

Gunakan menu aplikasi (Activities / Show Apps) untuk mencari dan membuka aplikasi seperti Wireshark, Remmina, atau Brave Browser.

2

Buka Terminal

Tekan pintasan keyboard di bawah ini atau cari aplikasi Terminal langsung dari menu aplikasi GNOME.

Ctrl + Alt + T
3

Periksa Koneksi & Alamat IP

Jalankan perintah berikut di Terminal untuk mengecek antarmuka, rute, dan koneksi internet:

ip addr
ip route
ping -c 4 1.1.1.1
4

Jalankan Alat Sesuai Kebutuhan

Alat berbasis grafis (GUI) dapat dibuka langsung dari menu aplikasi; sedangkan alat berbasis baris perintah (CLI) dijalankan melalui Terminal.

5

Gunakan Hak Administrator Seperlunya

Tambahkan awalan sudo hanya untuk perintah yang memang memerlukannya (seperti packet capture). Selalu baca perintah sebelum menjalankannya.

Catatan Penting

Panduan ini mengasumsikan paket telah tersedia pada instalasi Netra OS. Nama paket atau perintah dapat berbeda menurut versi dan konfigurasi. Sebagian perintah memerlukan koneksi jaringan, hak akses tertentu, atau izin capture.

Bagian 06 Ethics, Security & Help

Catatan Keamanan & Bantuan

Etika & Legalitas Penggunaan

Lakukan pemindaian jaringan (scanning), penangkapan paket (packet capture), dan pengujian performa (throughput testing) hanya pada jaringan atau perangkat milik sendiri maupun yang telah memberikan izin resmi. Jangan pernah menyimpan, menyadap, atau membagikan data sensitif dan rahasia milik pengguna lain.

Dokumentasi & Parameter Perintah

Gunakan halaman manual bawaan Linux atau flag bantuan singkat untuk mempelajari opsi dan parameter tiap perintah CLI secara mendalam.

man nama_perintah
nama_perintah --help

Instalasi Paket via APT (Ubuntu 26.04 LTS)

Jika suatu alat tidak ditemukan pada sistem, pastikan paketnya sudah terpasang menggunakan manajer paket apt karena Netra OS dirancang berbasis Ubuntu 26.04 LTS.

sudo apt update && sudo apt install nama_paket
